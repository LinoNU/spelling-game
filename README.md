# 📚 Vocabulary Spelling Adventure Game

An interactive spelling practice game designed for Grade 6/7 students to master their weekly vocabulary words.

## 🎯 About

This educational spelling game was created by Lino for his daughter Emilia's Grade 6/7 class, taught by Ms. Huang. The game transforms vocabulary practice into an engaging, interactive experience that helps students learn both spelling and word meanings.

## 🎮 Play the Game

**Access the game directly at:** [https://linonu.github.io/spelling-game/](https://linonu.github.io/spelling-game/)

The game works on any device with a web browser - computers, tablets, and phones!

## ✨ Features

- **Definition-Based Learning**: Students see the word's meaning and must spell it correctly
- **Strategic Letter Hints**: Each word starts with a few letters revealed to guide spelling
- **Progressive Hint System**: Students can request additional letters if needed (affects score)
- **Immediate Feedback**: Clear indication of correct/incorrect attempts with encouraging messages
- **Score Tracking**: Points system rewards accuracy and minimal hint usage
- **Randomized Practice**: Words appear in different order each round to prevent memorization
- **Mobile-Friendly**: Responsive design works on all devices

## 📝 How It Works

1. **Read the Definition**: Each round presents a word's meaning
2. **View Letter Pattern**: See the word length with some letters revealed (e.g., W _ _ _ L _ _ for "waggles")
3. **Type Your Answer**: Enter the correct spelling based on the clues
4. **Get Feedback**: Receive immediate confirmation if correct or hints if incorrect
5. **Use Hints Wisely**: Request more letters if stuck (reduces points earned)
6. **Complete All Words**: Practice all vocabulary words and see your final score

## 🎓 Educational Benefits

- **Reinforces Vocabulary**: Students learn word meanings alongside spelling
- **Encourages Problem-Solving**: Letter patterns help develop spelling strategies
- **Builds Confidence**: Non-punitive approach with encouraging feedback
- **Promotes Repetition**: Gamification encourages multiple practice rounds
- **Supports Different Learning Speeds**: Students can take their time or use hints as needed
